# Vision

Storyworks is a **local-first** pre-production writing studio for novels, screenplays, notes, journals, and worldbuilding. AI is a tool in the room (Muse, Writers Room later)—not the author of record.

## Principles

- Manuscripts live on disk under `projects/`, versioned per project.
- Ollama-first; OpenClaw optional bridge; cloud only when the user opts in.
- Human gates for design (Phase 1) and destructive actions (archive → typed delete).
- Light, gold-accented studio aesthetic—no dark mode product track.

## North star

One place to write early, then grow into Codex, Writers Room, git sync to private remotes, and procedural story systems—without ever dumping creative content into the public product repo.
