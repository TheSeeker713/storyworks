# 2026-08-08

Canvas SDK research landed a real conflict, not a maybe.

tldraw was still the best technical fit for TipTap cards, freehand, nested worlds — the product shape we locked. License doesn't work for where this goes: Storyworks → Mycelia → MyKAIA. Paid commercial or a permanent watermark. We're not buying that, and we're not shipping watermarked hobby mode into a commercial stack.

Excalidraw is MIT but doesn't cleanly host TipTap as a real card shape. `renderEmbeddable` is an iframe override. Force-fitting it would lie about what we built. React Flow can do TipTap nodes and edges, but it's a node-graph UX, not the writing surface we want as the primary thing.

So: drop third-party canvas SDKs entirely. Descope canvas from Phase 0. Rip tldraw out of the web app (package gone, CanvasBoard gone). Phase 0 writing is honest again — project list (create / open / archive / restore / typed delete) and a TipTap box that autosaves to vault `.md` on the path we already proved in 0.3. That's the real Phase 0 writing experience, not a throwaway stub.

Custom infinite canvas gets its own phase later (`PHASE_3_CUSTOM_CANVAS.md`), researched and spiked properly when we get there. Not under license panic tonight.
