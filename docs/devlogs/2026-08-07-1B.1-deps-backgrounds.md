# 1B.1 — R3F deps, ffmpeg/webp tooling, background convert path

Killed the old Phase 1 chrome plan in my head and started the redesign from the bottom: packages and asset plumbing first.

Installed `@react-three/fiber` 9, `three`, and `@react-three/drei` 10 under `apps/web` so React 19 stays on the matching line. Homebrew `ffmpeg` landed, but its bottle has no `libwebp` encoder, so conversion goes through `cwebp` (`brew install webp`) with ffmpeg as a fallback if that encoder ever shows up.

`assets/backgrounds/` is the drop zone. `scripts/convert-backgrounds.sh` writes `apps/web/public/backgrounds/bg-NNN.webp` plus `manifest.json`. Right now there's only a soft paper placeholder (`placeholder-atelier.png` → `bg-001.webp`) because I haven't dumped real stills in yet. Empty/raw dumps stay under `assets/backgrounds/raw/` and stay gitignored; converted webp + manifest are tracked so `/design` can boot without a local convert.

`--help` and `--dry-run` work. `pytest` 6/6. `npm run build` clean. Next is tearing out the tab sandbox and putting a full-bleed shell on top of this playlist.
