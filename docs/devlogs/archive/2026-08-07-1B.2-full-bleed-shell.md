# 1B.2 — Full-bleed shell, daily webp, solid modules

Tore out the tab chrome. `/design` is edge-to-edge now — no 1100px card page, no production topbar on that route. Brand sits in the design chrome itself and links back to Projects.

Daily playlist lives in `backgroundPlaylist.ts`: shuffle once, one asset per calendar day, same image all day, advance and reshuffle when the cycle wraps. Opacity slider sticks in localStorage. Debug line shows today’s asset id (`bg-001` until I drop real stills into `assets/backgrounds/`).

Modules are Prompt / Note / Novel / Screenplay / Journal as flat solid panels. Switching them runs a short rise animation and a one-shot background parallax, then the BG goes static again. Muse Tab/dismiss copy is still on the Novel mock only.

`pytest` 6/6, `npm run build` clean. Next pass is hover aides everywhere and the R3F drawer prototype.
