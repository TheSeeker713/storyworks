## Naming (locked)

**One file per calendar day:** `YYYY-MM-DD.md`

Example: `2026-08-07.md`

Within that file, **append** timestamped entries (do not overwrite earlier entries):

```markdown
## HH:MM

…first-person notes for this step or session chunk…
```

Use local time. At the end of every phase step, append an entry to **today’s** file (create the file if it does not exist yet).

## Archive

Older per-step filenames (`YYYY-MM-DD-phase-step-slug.md`) live under [`archive/`](archive/) for history only. Do not create new per-step files.
